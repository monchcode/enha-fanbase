# 1009 UNIVERSE

A dedicated fan-made website for the k-pop group ENHYPEN and the fandom ENGENE.

## About

1009 UNIVERSE is a fanbase website created to bring ENGENEs together in one big community. The site provides updates, information, media archives, achievements, and resources for both new and longtime fans.

Whether you're discovering ENHYPEN for the first time or you've been here since I-LAND, this website can be a reliable and enjoyable space for staying connected with the group and the fandom.

## Features

- Latest ENHYPEN news and updates
- Member profiles and information
- ENHYPEN achievements and milestones
- Music and discography 
- Photos, videos, and media content
- Guides for Baby ENGENEs
- Events and comeback information
- Community resources and fan projects

## Sections

### News
Stay updated with the latest announcements, schedules, releases, and activities.

### Members
Learn more about Jungwon, Heeseung (now recognized as a soloist with the name EVAN) , Jay, Jake, Sunghoon, Sunoo, and Ni-ki.

### Baby ENGENE Guide
A beginner-friendly section for new fans, including member introductions, streaming guides, and helpful resources.

### Achievements
A collection of awards, chart records, career milestones, and memorable accomplishments both for the group and the fandom.

### Media
Browse photos, videos, interviews, and other ENHYPEN content.

### Music
Explore albums, singles, soundtracks, and the group's complete discography.
